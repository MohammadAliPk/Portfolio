# Mohammad Ali Salimian — Portfolio

Interactive front-end portfolio with scroll animations (GSAP), dark/light theme, and EN/FA language toggle.

## Stack

- React + TypeScript + Vite
- GSAP ScrollTrigger

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
